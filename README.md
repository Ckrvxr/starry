# Starry

Starry 是一个基于 **Qt 6 + libmpv** 的跨平台流媒体播放器。支持 macOS、Windows 和 Linux。（目前只在 Mac 上积极开发）

## 功能

- Emby 服务器支持
- libmpv 原生内嵌渲染和硬件解码

## 开发依赖

- CMake 3.24+
- Qt 6.5+：Core、Gui、Quick、Qml、Network、OpenGL
- libmpv 0.35+
- pkg-config
